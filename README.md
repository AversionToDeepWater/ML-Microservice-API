## Project Scope and Objectives 
The purpose of this project is perfom continuous delivery and demonstarte the skills learnt so far in the Cloud DevOps Course.

This will be showhn through the creation of a Python-based machine learning application using the Flask web framework. 

A pre-trained sklearn model is provided. This model has been trained to predict hosue prices in Boston, US. 

This application is automatically deployed into Azure App Services through the CI/CD pipeline.
